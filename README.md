### 🚀 Featured Project

#### 📋 [LibreOMR](https://github.com/foxzyt/LibreOMR)
A modern, offline-first Optical Mark Recognition (OMR) application designed for teachers and educational institutions to automatically grade answer sheets via camera photos or flatbed scans.

- **Zero Heavy Dependencies**: Custom computer vision and fiducial alignment pipeline built from scratch in lightweight C++.
- **Complete Suite**: Batch processing, psychometric & IRT item diagnostics, automated PDF report generation, and printable A4 sheet designer.
- **Offline & Private**: 100% local execution ensuring student data privacy.

*Status: Active Development • v1.2.x*
